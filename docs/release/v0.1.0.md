The first downloadable build of **bbport for Mac**: *Bloodborne* on Apple Silicon, based on
[bbport 0.4](https://github.com/deadinside28/bloodborne_pc) by deadinside28. **Experimental.**

**No game files are included.** You need your own decrypted copy of Bloodborne (CUSA03173)
merged with the 1.09 update.

### Install

1. Download `bbport-mac-0.1.0.zip` below, open it and drag **bbport.app** into Applications.
2. Install Rosetta 2 and the Command Line Tools if you don't have them (the commands are in
   the read-me in the zip).
3. The app isn't notarised: on first open, use **System Settings ▸ Privacy & Security ▸ Open
   Anyway**.

Step by step, with the settings explained: **[User guide](https://github.com/bmy/bbport-mac/blob/macos-0.4/docs/USER_GUIDE.md)**.

Needs an Apple Silicon Mac with **macOS 26 or later**. Tested on one machine so far (M5 Max,
macOS 27): reports from other Macs are very welcome.

### What works

- The whole game boots, plays, saves and loads, with sound, cutscenes, a DualSense or other
  controller, and the keyboard (including text entry for names).
- 60 FPS (community frame-rate patch), output up to 4K, AMD FSR 3.1 or TAA anti-aliasing and
  upscaling, and experimental Apple MetalFX.
- The in-game settings menu (F1, ` or §; L3+R3), mods, and shadPS4-format patches.
- bbport 0.4's *Model detail: Highest*, which keeps the most detailed models at every distance.
- About **45–60 FPS** at 1440p with FSR 3.1 Native AA on an M5 Max; busy areas are the slow
  ones.

### Recent changes

- **One self-contained app**: no Homebrew, no build, no checkout. Settings, saves and logs live
  in `~/Library/Application Support/bbport`.
- The app has a **Help menu** (user guide, release notes, problem reports, the last run's log).
- **Loading screens show the item picture again** (it vanished for most of each loading screen,
  on Linux and Windows builds too).
- Keyboard input fixes, a Retina-resolution window, faster startup with the compiled-shader
  cache, and steadier camera motion vectors for FSR.

### Known limitations

- **Geometry shaders**: Metal has none, so a few effects that need them are missing.
- **Busy scenes run below 60 FPS.** The game and the graphics driver run under Rosetta 2; a
  native renderer is being worked on (the `macos-native` branch, for source builds).
- **Occasional pop-in** of objects while an area streams in.
- The first launch, and the first after each update, compiles shaders (black screen,
  stutter); later launches are quick.

Report problems on the [Issues page](https://github.com/bmy/bbport-mac/issues) with the log
attached (Help ▸ Show the Last Run's Log). Please don't report Mac problems to shadPS4 or to
upstream bbport.
