A new build of **bbport for Mac**, Bloodborne on Apple Silicon. **Experimental.** No game files
are included: you need your own decrypted copy of Bloodborne (CUSA03173) merged with the 1.09
update.

Download the zip below, open it and drag **bbport.app** into Applications, replacing the old
one (your settings and saves are kept). New users: see the
**[user guide](https://github.com/bmy/bbport-mac/blob/macos-0.4/docs/USER_GUIDE.md)**.

What changed: see the commits since the previous release.

Report problems on the [Issues page](https://github.com/bmy/bbport-mac/issues) with the log
attached (Help ▸ Show the Last Run's Log).
